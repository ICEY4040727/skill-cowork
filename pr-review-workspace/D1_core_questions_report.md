### 答案：❌ **迁移链有分叉，不干净！**

### 验证命令输出

```
alembic history 输出：

2026_04_06_002 -> 2026_04_08_001 (head)    ← Head 1
2026_04_06_002 -> add_course_meta_json (head)  ← Head 2（分叉！）
2026_04_06_001 -> 2026_04_06_002 (branchpoint)
<base> -> 2026_04_06_001
```

### 问题分析

1. **两个独立的 head**：迁移链在 `2026_04_06_002` 分叉
   - 分支 1: `2026_04_06_002 -> 2026_04_08_001` (添加 Character title)
   - 分支 2: `2026_04_06_002 -> add_course_meta_json` (添加 course meta json)

2. **FK 循环依赖警告**：
   ```
   SAWarning: Cannot correctly sort tables; there are unresolvable cycles 
   between tables "checkpoints, sessions"
   ```

3. **无法确定哪个是真正的 head**

### 风险
- 从空库执行 `alembic upgrade head` 会失败
- 需要手动指定 `alembic upgrade <revision_id>`
