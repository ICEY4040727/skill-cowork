## Findings

### 1. [Medium] Session.course_id 和 Session.world_id 的 ondelete="CASCADE" 可能导致级联删除会话
- **Evidence**: `backend/models/models.py:228-230`
  ```python
  course_id = Column(Integer, ForeignKey("courses.id", ondelete="CASCADE"), nullable=False)
  world_id = Column(Integer, ForeignKey("worlds.id", ondelete="CASCADE"), nullable=False)
  ```
- **Impact**: 删除 Course 或 World 会级联删除所有关联的 Session 和 ChatMessage，用户可能丢失对话历史
- **Suggestion**: 考虑改为 `ondelete="SET NULL"` + `nullable=True`，或在删除前警告用户；至少在文档中明确此行为
